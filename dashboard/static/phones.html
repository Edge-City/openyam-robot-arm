Phones

Phones on the same Wi-Fi open these pages from dashboard/phonecam.py (HTTPS, port 8443). Every page needs the access token, which the QR codes and links carry. The token is a secret on shared Wi-Fi, so the codes stay hidden until you show them.

First time on a phone

  1. Join the same Wi-Fi as this laptop, then scan a QR code with the phone camera.
  2. Accept the certificate warning (the certificate is self-signed). iPhone: Show Details → visit this website. Android: Advanced → Proceed.
  3. Camera: pick a name (side, top, …), tap Start and allow the camera. Keep the phone plugged in.
  4. Tilt / Joystick: tap “Ask for control”, then approve it in the console's Programs panel. They drive the armctl daemon (currently the simulated arm); the arm moves only while you hold a button or a stick.
  5. Once a phone has opened one page, the header on each phone page switches between Camera, Tilt and Joystick.

Firewall: phones need sudo ufw allow from 192.168.100.0/24 to any port 8443 proto tcp. To change the token, delete dashboard/certs/token and restart phonecam.
